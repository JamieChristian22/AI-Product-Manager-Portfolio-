# Label Governance

## Activation Label
Defined as completion of the product's agreed Core Value Event within 7 days of signup.

## Early Churn Label
No qualifying engagement in the 7 days after prior active state, adjusted for expected product-use frequency.

## Paid Conversion Label
First paid plan activation within the attribution window.

## Positive Intervention Response
A qualified downstream action after exposure, excluding accidental clicks and immediate reversals.

## Label Change Rules
Any change to:
- activation definition
- churn window
- paid conversion attribution
- core value event
requires a new label version and model revalidation.

## Leakage Rule
No event occurring after the prediction timestamp may be used as a feature for that prediction.
