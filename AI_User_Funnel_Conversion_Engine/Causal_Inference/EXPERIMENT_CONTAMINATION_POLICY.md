# Experiment Contamination Policy

## Risks
- user sees multiple conflicting treatments
- cross-device reassignment
- lifecycle email and in-product experiment overlap
- support team manually changes user state
- shared-account users receive mixed experiences

## Controls
- persistent user-level assignment
- experiment exclusion groups
- intervention ledger
- cross-channel experiment registry
- intent-to-treat analysis
- contamination-rate reporting

## Critical Threshold
If treatment contamination exceeds 5%, the experiment requires analytic review before decisioning.
