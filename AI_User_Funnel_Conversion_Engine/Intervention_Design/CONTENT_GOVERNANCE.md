# Intervention Content Governance

## Every Message Must
- identify a real product benefit
- be truthful
- be dismissible when appropriate
- avoid fabricated urgency
- avoid shame or guilt
- avoid sensitive inference
- match current user state

## Review Checklist
- Is the message accurate?
- Is the urgency real?
- Can the user decline?
- Is the recommended next action actually useful?
- Would the wording still be acceptable if shown publicly?
- Is the message more helpful than manipulative?

## High-Risk Copy Examples
Prohibited:
“You’re falling behind.”
“Upgrade now before you lose access” when access is not actually expiring.
“We know you need this” based on inferred behavior.
