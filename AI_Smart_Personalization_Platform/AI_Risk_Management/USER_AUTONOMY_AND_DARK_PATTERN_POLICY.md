# User Autonomy & Dark Pattern Policy

The platform must not:
- fabricate scarcity,
- create false urgency,
- repeatedly resurface explicitly disliked items,
- conceal the personalization opt-out,
- infer sensitive life events,
- exploit financial vulnerability,
- manipulate users with deceptive recommendation explanations.

The platform should:
- provide visible personalization controls,
- allow negative feedback,
- explain recommendations in plain language,
- preserve discovery outside prior behavior,
- offer a non-personalized fallback,
- measure long-term satisfaction alongside conversion.
